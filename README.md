# 📐 Figuras Geométricas (LPOO)

> Projeto acadêmico desenvolvido em **Java** para a disciplina de Linguagem de Programação Orientada a Objetos (LPOO), com foco na implementação de interfaces, contratos de comportamento, métodos `default` e polimorfismo aplicados a formas geométricas.

---

## 🚀 Sobre o Projeto

O objetivo principal desta aplicação é modelar um sistema de cálculo de áreas e perímetros utilizando uma interface comum (`Forma Geométrica`). O projeto explora conceitos avançados de POO em Java, como a utilização de múltiplos comportamentos via interface, reutilização de código com métodos `default` e a implementação concreta por diferentes classes de figuras.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java
* **Ambiente de Desenvolvimento:** Visual Studio Code
* **Controle de Versão:** Git e GitHub

---

## 📦 Estrutura e Modelagem

O sistema é centrado em torno da interface `Forma Geométrica`, que define os contratos obrigatórios para o cálculo de propriedades matemáticas:

* **Interface Principal:** `FormaGeometrica`
  * Métodos abstratos/padrão: `calcularPerimetro()`, `calcularArea()`, e `getForma()`.
* **Classes Concretas Implementadoras:**
  * `Quadrado`
  * `Retangulo`
  * `Triangulo`
  * `Circulo`
